# Khan's Art - Gallery of Ali Khan 🎨

A simple and elegant online **art gallery** showcasing Ali Khan’s paintings, digital artworks, and other creative designs.  
This project is built with **HTML, CSS, and PWA (Progressive Web App)** features.

---

## 🌐 Live Demo
👉 [Khan's Art Gallery](https://khansart.netlify.app/)

---

## 📖 Features
- Responsive design (works great on mobile, tablet, and desktop)  
- SEO-optimized meta tags  
- Open Graph support (Facebook, LinkedIn) and Twitter Cards  
- Custom favicons for different platforms  
- PWA support with `manifest.json` (can be installed like an app)
